# Security policy

Glint reads file names (not file contents) from the NTFS index, and the
"Full disk search" install runs it with administrator rights through a
scheduled task. Please report anything that could let another program or
user abuse that.

## Reporting a vulnerability

Use [private vulnerability reporting](https://github.com/ThisXNeural/Glint/security/advisories/new)
instead of a public issue. You should get a reply within a week.

## Supported versions

Only the latest release receives fixes.
